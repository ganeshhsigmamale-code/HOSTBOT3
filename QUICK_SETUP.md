# ⚡ Quick Setup Guide - Railway

## 2 Simple Steps (Seriously!)

### 1️⃣ Railway Deploy (1 minute)
```
1. https://railway.app
2. New Project → GitHub repo
3. Select: host-bot
4. Wait for deploy
```

### 2️⃣ Done! 🎉
```
Kuch aur karne ki zarurat nahi!
No environment variables needed!
```
